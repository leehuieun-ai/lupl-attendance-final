# Repository Working Rules

Use Ponytail-style judgment for this project:

1. First ask whether the change really needs new code.
2. Reuse the existing component, helper, table, or pattern before adding one.
3. Prefer standard browser/React/Supabase APIs over extra dependencies.
4. Keep the smallest correct change that preserves validation, security, payroll accuracy, and employee privacy.
5. Do not rename user-facing business terms unless the request asks for it.
6. Verify with type check/build before deploy when code changes.
